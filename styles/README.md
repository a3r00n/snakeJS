# Snake JS

[![Version](https://img.shields.io/github/v/tag/a3r00n/snakeJS)](https://github.com/a3r00n/snakeJS/tags)

A classic Snake game built from scratch with vanilla JavaScript, HTML, and CSS.

## Preview

![Snake JS Preview](./assets/preview-v0.1.0.png)

## Features

- Snake movement with arrow keys
- Food spawning
- Snake growth
- Wall collision
- Self-collision
- Canvas-based rendering

## Tech Stack

- HTML
- CSS
- JavaScript
- HTML Canvas
